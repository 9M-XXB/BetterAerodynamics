# 更好的空气动力学

[English](./README.md) | **简体中文**

## 适用版本

这个模组是基于Minecraft 26.1.2和Fabric0.19.3的。

## 模组作用

这个模组为游戏中的鞘翅提供了一个基本的，更加空气动力学的物理引擎。 模组默认假设鞘翅拥有一个NACA2412的翼型，但可以在设置界面（按 **O** 打开）中自定义——内置的 NACA 四位数字翼型构建器会实时重建飞行模型。 模组会根据玩家实时的速度来计算鞘翅表面的附面层，并且通过面元法与3D机翼修正来得到鞘翅产生的升力与阻力。转弯同样采用物理建模——压坡度转弯（banked lift）：看向一侧会使鞘翅倾斜，升力矢量的水平分量使飞行轨迹弯曲；和真实滑翔机一样，持续转弯不拉杆就会掉高度，转弯中拉杆过猛也可能失速。最终的目标是给游戏里的鞘翅一个更真实的飞行手感。

模组通过加入国际标准大气数据（ISA）来支撑空气动力学计算。默认使用常规换算——与速度换算同一尺度：1 格 = 1 米（3.28 英尺），游戏内海平面读作 0 英尺。换算方式可在模组设置界面中修改（游戏内按 **O** 打开，键位可在控制设置中更改）：除常规换算外，还提供"珠峰映射"模式，用两个输入框手动设定海平面 Y 与珠穆朗玛峰 Y，换算会在两者之间线性缩放，使珠峰 Y 读作 8848 米（29031 英尺）——例如海平面保持游戏内海平面、珠峰 Y 填 320，即可把建筑高度上限映射到珠峰高度。同一个设置界面里也可以开关 HUD 显示（与 /aerohud 命令共用同一状态，重启后保留）。为了让玩家更好的认知到自己所处情况，模组加入了显示高度与垂直速度的HUD。这个HUD很不方便的使用了英尺与英尺每分钟作为单位，因为这是所谓“航空单位”，也是表达了作者对于这些个破单位的怨念。
