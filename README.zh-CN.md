# 更好的空气动力学

[English](./README.md) | **简体中文**

## 适用版本

这个模组是基于Minecraft 26.1.2和Fabric0.19.3的。

## 模组作用

这个模组为游戏中的鞘翅提供了一个基本的，更加空气动力学的物理引擎。 模组假设鞘翅拥有一个NACA2412的翼型（虽然理论上所有4个数字的NACA翼型都是支持的）。 模组会根据玩家实时的速度来计算鞘翅表面的附面层，并且通过面元法与3D机翼修正来得到鞘翅产生的升力与阻力。最终的目标是给游戏里的鞘翅一个更真实的飞行手感。

模组通过加入国际标准大气数据（ISA）来支撑空气动力学计算。这个ISA模型经历了MC特色的特调。目前将游戏内海平面（y=70）设置为ISA中的海平面，建筑高度限制（y=320）设置为珠峰高度。但是这个奇特的高度换算方式只存在于获取大气数据，其他空气动力学计算依旧使用传统的一格等于一米。为了让玩家更好的认知到自己所处情况，模组加入了显示高度与垂直速度的HUD。这个HUD很不方便的使用了英尺与英尺每分钟作为单位，因为这是所谓“航空单位”，也是表达了作者对于这些个破单位的怨念。
